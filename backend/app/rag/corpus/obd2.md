# OBD-II concepts — internal demonstration

Generic internally authored reference. No copyrighted DTC catalog is reproduced.

## Diagnostic trouble codes

A diagnostic trouble code records a condition detected by a control system. It is a
clue for investigation, not proof that a named component must be replaced. The full
code, associated observations and verified documentation matter. A qualified
technician may need to read stored information and perform supported checks. Never
invent a manufacturer-specific meaning or procedure from a code alone.

## Códigos de avería

Un código de avería es una pista. No confirma por sí solo la pieza defectuosa.
Conserva el código completo y solicita una comprobación profesional con información
técnica adecuada. No borres avisos para ocultar un problema de seguridad.

# Vehicle asset

`golf-viii-gti.glb` is the approved illustrative Golf VIII GTI, used by Home and
My Vehicle. Its locally rendered poster is also used for loading/error states.
The diagnostic vehicle remains Golf Plus 2009/CFFB. Credits and this distinction
are available via the viewer information icon and Settings → Asset Credits.

Author: Mona x Supercars / Car2022; embedded GT Cars: Hyperspeed credit retained.

See [all asset credits](../../../docs/ASSET_CREDITS.md).

The source GLB is unchanged (3,794,336 bytes). Local Three/Fiber/Drei loading
requires no Sketchfab login, iframe or external texture/decoder service. No old
concept car or unrelated static vehicle image is bundled.
